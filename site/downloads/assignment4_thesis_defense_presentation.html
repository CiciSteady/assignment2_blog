Concept

Protect the thesis core under academic pressure

Game Theme

  • The player is a graduate student defender.
  • The center objective is the thesis core and defense gate.
  • Bugs attack the Code Lab, Deadlines attack the Schedule Gate, and Peer Reviewers attack the Committee Door.
  • Gate archers shoot matching attackers from range.
  • If an archer is pinned down, the player must rescue them with a sword.
  • Citations are collectibles that increase the final score.
  • Successful defense weakens threats; failed defense makes them stronger.
Game concept3 / 8

Gameplay

Short, playable, and easy to demonstrate

Key Features

  • Character selection screen with seven playable roles.
  • Keyboard controls with Arrow keys or WASD.
  • Mouse and touch movement by clicking the canvas.
  • Score, defended count, integrity, rejection gate, timer, and threat strength HUD.
  • Gate archer helpers, arrow projectiles, and sword rescue moments.
  • Clear pass/fail logic: survive 60 seconds, or lose by collapse/rejection.

Architecture

Static HTML, CSS, and JavaScript

Core Files

  • thesis_defense_game.html: game page and interface.
  • thesis_defense_game.js: state, rendering, collision, scoring.
  • style.css: shared blog design and game layout.

Game Loop

  • Update player movement and target position.
  • Move threats toward their target objects with tile-based route selection.
  • Let gate archers shoot matching attackers using cooldowns and arrows.
  • Check sword rescues, collisions, citations, and pass/fail pressure.
  • Redraw the maze, player, archers, humanoid threats, arrows, particles, and HUD.
